# Rafik Baig – Portfolio

Static site (one `index.html`, no build step).

## Publish on GitHub Pages
1. Create a repo named `rafik-baig.github.io` (or any name).
2. Upload everything in this folder (`index.html`, `assets/`, `README.md`).
3. Repo Settings → Pages → Source: "Deploy from a branch" → `main` / root.
4. Your site appears at `https://<username>.github.io/` in about a minute.

Add images to `assets/` and reference them in `index.html`.
